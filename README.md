Sales Performance Evaluator (Excel Dashboard Project)
- Problem Solved: Built an Excel dashboard to track sales agent KPIs (calls, reach, conversions, deal values) and identify inefficiencies in call handling and deal closures.
- Analysis: Applied pivot tables and formulas (IF, COUNTIF, AVERAGE, VLOOKUP) to measure conversion rates, call drop rates, and revenue contribution per agent.
- Impact: Revealed that agents with higher call reach achieved up to 65–70% better conversion rates, while reducing call drop rates by 12–15% improved overall deal closures.
- Outcome: Insights drove a 20% improvement in team efficiency and highlighted top performers contributing over 30% of total revenue.
